Analysis Scenarios

01

Effect of the Number of Neighbours (K)

Procedure:
  1. Select different values of K (for example 6, 8 and 10).
  2. Train the model for each value of K.
  3. Observe the decision boundary visualization and performance metrics.
  4. Record the values of Accuracy, Precision, Recall and F1-Score.
Expected Observations:
  • Smaller values of K produce irregular or noisy decision boundaries, leading to possible overfitting.
  • Larger values of K produce smoother boundaries, leading to possible underfitting.
  • Moderate values of K produce balanced boundaries, leading to better generalization.
02

Effect of Training Sample Size

Procedure:
  1. Use the Sample Size buttons to change the number of training samples.
  2. Train the model with different sample sizes (for example 30, 60, 90 and 105).
  3. Observe how the performance metrics change.
Expected Observations:
  • When the number of training samples is small, the model has limited information, leading to unstable predictions and irregular decision boundaries.
  • As the number of training samples increases, the classifier captures the data distribution more effectively, improving classification performance.
  • Performance metrics such as Accuracy, Precision, Recall and F1-Score become more stable with more training data.
  • The decision boundary becomes more consistent and reliable as the model learns better class separation from a larger dataset.
03

Effect of Distance Metric on Classification

Procedure:
  1. Select Euclidean Distance as the distance metric.
  2. Train the model and record metrics.
  3. Switch to Manhattan Distance while keeping the same value of K.
  4. Train again and observe the changes in classification predictions and decision boundaries.
Expected Observations:
  • Different distance metrics may select different neighbouring points for the same test sample because the method of distance calculation varies.
  • Due to this difference in neighbour selection, the predicted class for some samples may change when the distance metric is altered.
  • Compare the performance metrics to determine which distance metric provides better classification performance for the given dataset.
04

Effect of Feature Scaling

Procedure:
  1. Select No Scaling as the scaling option.
  2. Train the KNN model and record metrics.
  3. Switch to Standard Scaling.
  4. Train again and observe the decision boundary and performance metrics.
Expected Observations:
  • Without feature scaling, features with larger numerical values may dominate the distance calculation, which can influence neighbour selection and reduce classification performance.
  • After applying feature scaling, all features contribute more equally to the distance computation, which may improve the classification results.
  • The decision boundary often becomes more balanced and consistent when normalization is applied.
